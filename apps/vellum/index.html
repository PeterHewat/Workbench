        Help
        
        
        
        
        
          
        Tools
        
          
          
            
        • 
              Select (S) — the resting state, with no drawing tool chosen: click a shape to
              select it (thin strokes have a wider invisible click area, and the shape under the
              cursor is outlined in blue), drag to move, drag on empty space for a marquee.
              Shift-click adds to the selection. A shape only starts moving once the pointer has
              really travelled, so a click that selects never nudges anything.
            
          • 
            
        • 
              Panning — hold Space and drag, or drag with the middle mouse button.
              On a touch screen, drag on empty canvas with one finger. The mouse wheel zooms, two
              fingers pinch. There is no separate hand tool to switch to.
            
          • 
            
        • 
              Pen (P) — click for corner points, click-drag for curves. Double-click or
              Enter finishes; click the start point to close. A path with no curves
              becomes a line, polyline or polygon automatically. Esc cancels.
            
          • 
            
        • 
              Rectangle (R) / Ellipse (E) — drag, or click twice. Shift makes a
              square / circle.
            
          • 
            
        • 
              Arc (A) — drag from one end of the arc to the other and it bulges a quarter
              turn to the right; hold Shift for a half circle. The result is an ordinary
              two-point curve, so reshaping it afterwards means dragging its handles.
            
          • 
            
        • 
              Text (T) — click to place, then type in the field that opens in the SVG panel.
            
          • 
          
        

          
        Editing shapes
        
          
          
            
        • 
              Resize — drag the blue handles. Rectangles also have a corner handle just
              inside the top-right corner; drag it to round the corners, hold Alt to set
              horizontal and vertical radii separately.
            
          • 
            
        • 
              Rotate — drag the pink handle above a selected shape. Shift snaps to
              15°. Rectangles become polygons and ellipses become paths the first time they are
              rotated; text keeps its type and has a Rotation field.
            
          • 
            
        • Nudge — arrow keys move by 1 unit, Shift by 10.
          • 
            
        • 
              Align — hold Alt while drawing or dragging to snap to points that
              line up horizontally or vertically with other shapes (this replaces grid snapping
              while held).
            
          • 
            
        • 
              Z-order — Ctrl+[ / ] sends backward / forward.
              In the Primitives and Reference images lists, use the ▲ ▼ buttons on a row to move it
              one step (Shift+click: to the top or bottom).
            
          • 
          
        

          
        Paths and curves
        
          
          
            
        • 
              Add a point — double-click on a segment of the selected shape. Curves are split
              without changing their shape.
            
          • 
            
        • 
              Remove a point — click it, press Delete. Its neighbours are joined.
            
          • 
            
        • 
              Smooth ↔ corner — double-click an anchor. Lines, polylines and polygons turn
              into paths first.
            
          • 
            
        • 
              Curve handles — the two handles of a smooth point mirror each other. Hold
              Alt while dragging one to move it independently; release Alt to mirror
              again. A cusp is remembered until you drag a handle without Alt.
            
          • 
            
        • 
              Join — select two open paths and click Join in the Primitives header (or
              press J): they are connected at their closest ends. Or drag an end point
              onto another path's end point.
            
          • 
            
        • 
              Close / open — tick Closed in the shape's row, or drag an end point onto
              the other end point.
            
          • 
            
        • 
              Split — select a point and press X. An open path becomes two paths;
              a closed one becomes one open path cut at that point.
            
          • 
          
        

          
        Style (Primitives list)
        
          
          
            
        • 
              Stroke / Fill — click a swatch for the color picker (hue, saturation,
              brightness, hex and alpha). The Fill checkbox turns fill on or off.
            
          • 
            
        • 
              Fill type — Solid, Linear Gradient (with Angle) or Radial Gradient; both
              gradient colors have their own alpha.
            
          • 
            
        • 
              Width, Line cap, Line join — stroke geometry. Width 0 exports as no stroke.
            
          • 
            
        • 
              Start / End — arrow, dot, square or diamond markers on lines, polylines and
              paths.
            
          • 
            
        • 
              Names — every shape gets a default name (path 1, rect 2, …) that stays with it
              when you move it; type in the row title to change it (clearing it restores a default).
              Exported as id="d8e4764a_name"; only the first underscore separates the
              generated id from your name.
            
          • 
            
        • 
              The colored square in each row shows the stroke as its border and the fill inside.
            
          • 
          
        

          
        Groups
        
          
          
            
        • 
              Ctrl+G groups the selection,
              Ctrl+Shift+G ungroups. Clicking a member selects the
              whole group; the ◉ / ○ button in the list selects single members. Exported as
              <g>.
            
          • 
          
        

          
        Clipboard
        
          
          
            
        • 
              Ctrl+C / X / V copy, cut and paste shapes
              (offset each time). Paste also accepts SVG markup copied from anywhere, and works
              between browser tabs. Ctrl+D duplicates.
            
          • 
          
        

          
        History
        
          
          
            
        • 
              Undo / Redo buttons in the toolbar, or Ctrl+Z /
              Ctrl+Y.
            
          • 
          
        

          
        Document panel
        
          
          
            
        • 
              The Document button (first in the toolbar) toggles a panel docked on the left.
              It floats over the canvas and stays open while you work. Its sections (Documents,
              Reference images, SVG, Primitives) fold open and closed, and are remembered.
            
          • 
            
        • 
              Reference images — add reference images to trace; each has visibility, opacity,
              position, scale and rotation.
            
          • 
            
        • 
              SVG — the artboard size (width × height) and the live markup, which you can
              edit directly: changes apply to the drawing after a short pause (an error
              message appears if the markup is invalid, and nothing is changed until it is valid).
              Click or move the cursor into a shape's line and that shape is selected, exactly as if
              you had picked it in Primitives; selected shapes are shown in blue. When a field in a
              Primitives row has focus, the SVG attribute it edits is highlighted in yellow, even if
              the shape is not selected. Only shapes the app knows (path, line, rect, circle,
              ellipse, polyline, polygon, text) are kept. Icons import, export and copy the SVG
              (coordinates are exported as integers).
            
          • 
            
        • Primitives — one row per shape (see Style).
          • 
            
        • 
              Documents save automatically, like Pages or Notes on macOS — there is no Save button.
              Documents lists everything stored in this browser (reference images included).
              Click a document to open it; click the name of the open document to rename it in
              place. Hover a row for duplicate ⧉ and delete × (deleting an empty document doesn't
              ask; others do). + starts a new document (named Untitled, Untitled 2, …; the
              current one is already saved). The last document reopens when you start the app.
              Documents live in this browser only, so back them up: the ⬇ / ⬆ buttons in the
              Documents header export every document to one JSON file and restore them again
              (restored copies are added alongside your existing ones, never overwriting them). To
              empty a document, Ctrl+A then Delete.
            
          • 
          
        

          
        Toolbar: grid and view
        
          
          
            
        • 
              The grid button shows or hides the grid, and the small field next to it sets the grid
              step. The magnet (or G) toggles snap to grid; a marker shows where the
              point will land. Snapping applies to drawing, dragged handles and moved shapes; hold
              Alt to switch to alignment snapping instead.
            
          • 
            
        • 
              Fit view, 100% zoom, and the eye button (Final SVG only: hides the grid, guides
              and reference images).
            
          • 
          
        

          
        Rulers
        
          
          
            
        • 
              Rulers along the top and left show artboard units and a cursor marker. When the
              Document panel is open they start to its right.
            
          • 
          
        

          
        Touch
        
          
          
            
        • 
              One finger drags on empty canvas to pan; hold still for a moment first and the drag
              becomes a marquee selection instead. Two fingers pinch to zoom and pan. Double-tap
              finishes a pen path.
            
          • 
            
        • 
              Handles get a finger-sized target on a touch screen, and points that sit close
              together keep smaller ones so neighbours stay reachable. Zoom in where it is tight.
            
          • 
            
        • 
              Any tool can grab an existing handle: with the rectangle or ellipse tool active,
              touching a handle of a shape already on the canvas edits that shape rather than
              starting a new one.
            
          •

              S P R E A T

              Pan the view
            
        
            
        
              Enter / Esc
              Finish / cancel a path
            
        
            
        
              Delete
              Delete shape or selected point
            
        
            
        
              X / J
              Split path at selected point / join two selected paths
            
        
            
        
              Ctrl+Z / Ctrl+Y
              Undo / redo
            
        
            
        
              Ctrl+C / X / V / D
              Copy, cut, paste, duplicate
            
        
            
        
              Ctrl+G / Ctrl+Shift+G
              Group / ungroup
            
        
            
        
              Ctrl+A
              Select all shapes
            
        
            
        
              Ctrl+S / Ctrl+Shift+S
              Save now (autosave is always on) / export SVG
            
        
            
        
              Alt
              Align-snap; breaks handle symmetry while dragging a curve handle
            
        
            
        
              Shift
              Square / circle, 15° rotation steps, add to selection
